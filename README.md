# 🛒 My First Python Shop System

Привет! Это мой первый серьезный проект на Python. Я пишу его уже 18 дней, и это мой «тренажер» для погружения в бэкенд-разработку. 

### ⚡️ Что эта штука умеет:
* **Добавлять товары:** записывает имя, цену и остаток.
* **Показывать базу:** выводит всё в консоль и считает общую стоимость склада.
* **Удалять:** если товар закончился или больше не нужен — одно нажатие, и его нет.
* **Память:** всё сохраняется в JSON-файл. Даже если выключить комп, данные не пропадут.
